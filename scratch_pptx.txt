=== ppt/slides/slide11.xml ===
Configuración del Motor MySQL: El motor InnoDB es obligatorio en la base de datos para garantizar el soporte completo de restricciones de clave foránea (FK) y mantener la integridad referencial.
Secuencia de Servicios: Se debe verificar el inicio correcto del servicio de MySQL (puerto 3306) antes del arranque de Spring Boot para asegurar la correcta conexión del pool HikariCP.
Permisos de Directorio: La carpeta local destinada al almacenamiento de archivos adjuntos (/uploads) requiere permisos de lectura y escritura habilitados en el servidor.
Seguridad en Producción: Se recomienda habilitar un certificado TLS/HTTPS para el cifrado de datos en tránsito antes de realizar el despliegue final en producción.
Observaciones

Impacto Operativo: Elimina ineficiencias, demoras en historias clínicas e inconsistencias en el control del personal médico.

=== ppt/slides/slide3.xml ===
Desorganización de Citas
Frecuencia de cruce de horarios entre odontólogos e ineficiencia en la programación de consultas dentales.
Sin Plataforma Integrada
Falta de una estructura central para el registro seguro de credenciales, historiales y fichas médicas.
Pérdida de Solicitudes
Extravío de solicitudes registradas en formularios externos o en soporte físico de papel.
Falta de Auditoría de Roles
Ausencia de control estricto entre perfiles (administradores vs. doctores) sobre datos sensibles de pacientes.

=== ppt/slides/slide4.xml ===
1.2.1 Objetivo General
Desarrollar e implementar la plataforma web TuDentaria mediante la tecnología Spring Boot, Thymeleaf y MySQL para optimizar la gestión de personal médico, el flujo de atención a pacientes y la seguridad de datos dentro del entorno odontológico.
1.2.2 Objetivos Específicos
Backend Modular: Autenticación y autorización segura basada en roles utilizando Spring Security.
Interfaz Adaptativa: Frontend responsivo con Bootstrap 5 y Thymeleaf para PC y dispositivos móviles.
Persistencia Relacional: Base de datos relacional MySQL/PostgreSQL estructurada mediante Spring Data JPA.
Módulo de Administración: Panel centralizado para gestionar doctores, recibir solicitudes y registrar incidencias.

2.1.1 Reseña
Enfoque Nacional: Iniciativa tecnológica adaptada a la realidad operativa del sector salud peruano.
Stack Tecnológico: Integra buenas prácticas de ingeniería de software con Java 17 y Spring Boot 3.3.5.
Contenerización: Configuración estructurada mediante Docker para simplificar despliegues en entornos cloud.
2.1.2 Descripción de la Solución
Acceso Seguro: Sistema multi-rol con credenciales encriptadas mediante algoritmos de seguridad (BCrypt).
Panel Administrativo: Interfaz integral para coordinar doctores, atenciones y respuesta a incidencias médicas.
Portal Asistencial: Canal continuo para la gestión e historial del paciente en la clínica.
