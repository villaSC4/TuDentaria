# 🦷 TuDentaria

> **TuDentaria** es un sistema web de gestión clínica odontológica desarrollado con Spring Boot y Bootstrap.

---

## 🚀 Características Principales

- **Autenticación y Seguridad:** Control de acceso mediante inicio de sesión y gestión de roles.
- **Diseño Responsive:** Interfaz moderna y adaptable a dispositivos móviles, tablets y computadoras de escritorio.
- **Panel de Administración:**
  - Control y gestión del personal médico (doctores).
  - Recepción y administración de solicitudes enviadas desde el formulario web.

---

## 🛠️ Tecnologías Utilizadas

- **Backend:** Java, Spring Boot (Spring MVC, Spring Data JPA, Spring Security)
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Base de Datos:** MySQL / PostgreSQL
- **Control de Versiones:** Git

---

## 📋 Requisitos Previos

- **JDK 17** o superior
- **Maven** 3.8+
- **MySQL** / **PostgreSQL**
- Tu IDE de preferencia (IntelliJ IDEA, Eclipse, VS Code)
